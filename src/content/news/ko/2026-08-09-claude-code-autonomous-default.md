**한 줄 요약**: Anthropic이 코딩 에이전트 Claude Code의 기본 동작을 더 자율적인 실행 방식으로 바꿨다고 외신이 전했다.

### 핵심
- 보도에 따르면 Claude Code가 매 단계 사용자 승인을 받는 대신, 기본 설정에서 스스로 작업을 이어가는 방향으로 변경된 것으로 알려졌다.
- 대상은 Anthropic의 개발자용 에이전트 도구 'Claude Code'로, 파일 편집·명령 실행 등을 수행한다.
- 구체적 적용 범위와 안전장치(권한 모드, 롤백 등)에 대한 세부 사항은 원문 기준으로 추가 확인이 필요하다.

### 왜 중요한가
코딩 에이전트가 '승인 후 실행'에서 '기본 자율 실행'으로 이동하는 흐름은 개발 생산성을 높이지만, 검증·권한 관리의 부담도 함께 커진다. 기본값 변화는 다수 사용자의 실제 작업 방식에 곧바로 영향을 준다.
