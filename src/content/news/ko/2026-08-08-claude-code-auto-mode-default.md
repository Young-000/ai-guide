**한 줄 요약**: 앤트로픽이 Claude Code의 기본 동작을 '오토 모드'로 바꿔 개발자가 잘못된 승인으로 실수하는 상황을 줄이려 한다고 보도됐다.

### 핵심
- 코딩 어시스턴트 **Claude Code**의 기본 설정이 오토 모드(Auto Mode)로 전환된 것으로 알려졌다.
- 변경의 명분은 개발자가 **위험한 작업을 무심코 승인(bad approvals)**하는 실수를 방지하는 데 있다.
- 승인 흐름을 도구가 기본적으로 관리하도록 바꿔, 매 단계 수동 확인에 따르는 피로와 오승인 위험을 낮추려는 취지로 전해졌다.

### 왜 중요한가
AI 코딩 도구가 파일 수정·명령 실행 등 실제 작업을 수행하는 범위가 넓어지면서, '무엇을 자동으로 허용하고 무엇을 사람이 확인할지'가 핵심 안전장치가 됐다. 기본값을 바꾸는 결정은 수많은 개발자의 워크플로에 곧바로 영향을 준다.
