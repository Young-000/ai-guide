**한 줄 요약**: 포브스는 앤트로픽의 연환산 매출(run rate)이 650억 달러를 넘어섰다고 보도했으며, 기업공개(IPO)를 앞둔 시점의 수치로 전해졌다.

### 핵심
- 포브스에 따르면 앤트로픽의 run rate(현재 매출을 연 단위로 환산한 지표)가 650억 달러를 상회한 것으로 알려졌다.
- 이 수치는 앤트로픽이 IPO를 준비하는 국면에서 나온 것으로 보도됐다.
- run rate는 확정 연매출이 아니라 특정 시점 매출을 1년으로 환산한 추정치로, 성장 속도를 가늠하는 지표다.

### 왜 중요한가
빠르게 오르는 매출 지표는 IPO 밸류에이션의 근거가 되며, 클로드(Claude)로 대표되는 상용 AI 수요가 실제 매출로 이어지고 있음을 시사한다. 다만 run rate는 순간값 기반 추정이라 실제 연매출·수익성과는 구분해서 볼 필요가 있다.
