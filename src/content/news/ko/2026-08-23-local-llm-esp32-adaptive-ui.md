**한 줄 요약**: 한 개발자가 로컬 LLM을 약 30달러짜리 ESP32 디스플레이에 연결해, 질문할 때마다 화면 레이아웃을 새로 생성하는 실험을 XDA에 소개했다.

### 핵심
- 저가 ESP32 마이크로컨트롤러 디스플레이에 **로컬에서 구동되는 LLM**을 연결한 DIY 프로젝트로 알려졌다.
- 고정된 UI 대신, 사용자의 질문마다 **화면 인터페이스를 즉석에서 생성(generative UI)**하는 방식이 핵심이다.
- 클라우드 API가 아닌 로컬 모델을 활용해 **온디바이스·저비용 하드웨어**에서 동작하는 데 초점을 맞췄다.

### 왜 중요한가
LLM이 앱을 실행하는 것을 넘어 상황에 맞는 화면을 그때그때 만들어내는 '제너레이티브 UI' 흐름을, 값싼 메이커용 하드웨어에서 보여준 사례다. 고성능 서버 없이도 온디바이스 AI로 적응형 인터페이스가 가능하다는 방향성을 시사한다.
