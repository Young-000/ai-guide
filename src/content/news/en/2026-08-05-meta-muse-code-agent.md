**In one line**: Meta has reportedly introduced Muse Code, an AI agent built for writing code and automating development, stepping into the crowded coding-agent race.

### Key points
- Meta has launched a new coding AI agent called **Muse Code**, according to reports.
- The move is aimed at competing with rivals such as **OpenAI and Anthropic**, whose coding agents already lead the space.
- It signals direct competition in code generation and developer-workflow automation.

### Why it matters
Coding agents are a contested arena where Anthropic's Claude Code and OpenAI's developer tools have gained early traction. Meta's entry — backed by its large-scale infrastructure and open-source model assets (the Llama family) — could intensify competition in AI tools for developers.
