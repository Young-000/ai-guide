**In one line**: Oracle introduced long-term memory for OCI Generative AI, carrying context across multiple conversations.

### Key points
- According to Oracle's blog, OCI Generative AI now supports long-term memory that retains user context beyond a single chat session.
- The feature is described as reducing the need to re-enter information each session, carrying accumulated user details and preferences from one conversation into the next.
- Unlike the short-term context window within a single chat, this targets a persistent memory layer that spans sessions.

### Why it matters
Long-term memory is central to moving chatbots from one-off Q&A toward personalized assistants. Baking it into an enterprise cloud platform appears to be Oracle's bid to differentiate itself in the generative-AI infrastructure race against AWS, Google, and Microsoft.
