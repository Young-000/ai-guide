**In one line**: Anthropic has reportedly urged developers to use tokens more efficiently during Claude Code sessions with its AI coding tool.

### Key points
- According to reports, Anthropic offered guidance aimed at reducing unnecessary token consumption when working in Claude Code.
- Tokens are the basic unit an LLM uses to process input and output, and usage drives both cost and processing speed.
- Loading oversized context indiscriminately or firing repeated requests is said to burn through tokens quickly, raising inefficiency.

### Why it matters
As AI coding agents spread into real-world workflows, "token efficiency" is becoming a direct proxy for development cost and productivity. A tool provider issuing savings guidance itself suggests that optimizing usage patterns may become a core variable in AI development going forward.
