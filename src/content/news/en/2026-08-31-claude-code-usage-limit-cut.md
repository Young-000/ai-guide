**In one line**: Anthropic has reportedly cut Claude Code usage limits by about 17% after winding down a temporary promotional boost.

### Key points
- Reports say Anthropic reduced usage limits for Claude Code users by roughly 17%.
- The change follows the end of a temporary "promotional boost" that had been applied to allowances.
- In effect, it rolls back extra headroom that was added on a limited basis rather than imposing a wholly new cap.

### Why it matters
Claude Code has seen rapid adoption among developers, so limit changes directly affect how much paying users can do per day and how they perceive value. It reads as a signal that AI coding tools are moving past their growth phase into a period of tuning economics and resource allocation.
