**In one line**: Meta is giving away the code behind Muse so developers can bake it into their own devices.

### Key points
- Meta is reportedly distributing Muse-related code for free, according to TechCrunch.
- The stated goal is to push Muse into everyday hardware such as TVs and even toasters.
- Developers are expected to take the code and integrate it into their own gadgets.

### Why it matters
Releasing the code for free signals that Meta is prioritizing **broad adoption** of Muse over selling a single finished product. The wider the ecosystem grows, the greater Meta's platform leverage.
