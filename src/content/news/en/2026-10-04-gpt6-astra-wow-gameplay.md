**In one line**: A tech outlet reports that an OpenAI model it refers to as "GPT-6 Astra" played World of Warcraft (WoW) using only raw, unprocessed game data.

### Key points
- Interesting Engineering reported that an OpenAI model dubbed "GPT-6 Astra" took in raw game data — rather than pre-processed instructions — to operate in WoW.
- The report centers on the model acting directly on screen and state data without separate hand-labeling.
- The model name and its capabilities appear to come from the report itself and have not been formally announced by OpenAI.

### Why it matters
If accurate, handling a complex real-time game environment without preprocessing would signal progress toward general-purpose agents. But because the model name and figures are not confirmed by a primary source, this is best treated as a press report for now.
