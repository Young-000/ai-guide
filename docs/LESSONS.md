# LESSONS — 자율 사이클이 시작 전 반드시 읽는 함정 목록

> 이 프로젝트에서 과거 사이클이 배운 비자명한 교훈만 1줄씩. 범용 교훈은 `ops-vault/Learnings/` 참조.

## 2026-07-12 주간

- 야간 자율 사이클이 지난주 **최우선** 태스크(서버사이드 트래픽 카운터)를 건너뛰고 저위험 SEO 라우트(아카이브 등)만 머지함. 원인 추정: 태스크에 "Supabase 전용 테이블 적재"가 포함돼 야간 사이클이 DDL을 게이트로 오인하거나 진입장벽으로 회피. → 교훈: **인프라(DB 테이블 생성 등)가 얽힌 태스크는 PM이 비파괴 DDL을 미리 처리해 "코드만 붙이면 되는" 상태로 만들어 넘길 것.** 이번 주 PM이 `search_trends.page_views` 테이블을 직접 생성해 블로커 제거함. 다음 사이클은 upsert 코드만 붙이면 됨.
- 전용 스키마 **신규 테이블 생성은 D1 게이트가 아니다**(비파괴적). 파괴적 변경(DROP/컬럼 삭제/타입 변경)만 게이트. 야간 사이클이 이걸 몰라 회피할 수 있으니 태스크 근거에 "테이블 이미 존재/비파괴" 명시.
- 구독자 8주+ 연속 0건이 지속되는데 콘텐츠 엔진(406파일, 주 ~30쌍)은 정상. 발행량은 병목이 아님이 재확인됨 → 리필을 "더 많은 발행"이 아니라 계속 **전환 진입점(SubscribeBox 위치)·내부링크·측정**에 집중. 발행 태스크는 이번 리필에서 의도적으로 배제.
